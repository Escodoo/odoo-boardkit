Expenses overview dashboard template for Boardkit.

Adds a curated **Expenses Overview** template that managers can
instantiate from *From template* in the Boards catalogue. The board is
built on ``hr.expense`` and lands unpublished so it can be reviewed
before users see it.

It focuses on expense health: to-report and submitted backlogs, approved
totals and counts, approval rate, reimbursement queue, amount trends,
employee and category breakdowns, and a recent expenses list. Toggle
filters cover my expenses, to report, submitted and approved.

Usage
=====

Install this module (it auto-installs when Boardkit Dashboard and
Expenses are both installed).

As a Dashboard Manager, open *All Dashboards > Boards*, click *From
template*, and choose **Expenses Overview**. Optionally rename the board
in the wizard.

The board opens with the date filter on *This Month*. Live backlog tiles
(To Report, Submitted, To Reimburse) ignore that filter so they always
show the current queue. Approved totals and counts use *Expense Date*
and follow the date filter. Use the toggle filters (My Expenses, To
Report, Submitted, Approved) to narrow the other cards.

When installed with demo data, a published board is created from this
template and placed first (sequence ``-1``) under the related app menu.
