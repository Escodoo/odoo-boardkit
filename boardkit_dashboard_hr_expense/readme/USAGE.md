Install this module (it auto-installs when Boardkit Dashboard and Expenses are
both installed).

As a Dashboard Manager, open _All Dashboards > Boards_, click _From template_,
and choose **Expenses Overview**. Optionally rename the board in the wizard.

The board opens with the date filter on _This Month_. Live backlog tiles (To
Report, Submitted, To Reimburse) ignore that filter so they always show the
current queue. Approved totals and counts use _Expense Date_ and follow the
date filter. Use the toggle filters (My Expenses, To Report, Submitted,
Approved) to narrow the other cards.

Review the unpublished board, adjust items or filters, then publish and
optionally set a parent menu under Expenses.
