BoardKit AI

Optional Agno-powered intelligence on top of BoardKit Dashboard — without changing the core engine. Chat with the figures on any board, generate an insights narrative, explain a single tile, or turn a natural-language description into an unpublished board you can review before users see it. Each dashboard opts in with Enable AI.

On the dashboard

Ask the board, in plain language

Answers use the figures currently shown — including the active date preset and board filters. Ask the assistant to switch to this month or enable a known filter and the cards reload.

Ask AI

Side-panel chat

Open the dashboard and click Ask AI. A side panel keeps the thread while you explore figures, copy answers, and follow up after filter changes.

Generate with AI

From a description to a board

Dashboard → Configuration → Generate with AI. Describe the board in plain language. Created boards land unpublished so you can review items before publishing.

BoardKit Dashboard

Built on the BoardKit engine

This module is an AI companion for BoardKit Dashboard — the open-source engine that builds analytic boards on any Odoo model with tiles, KPIs, gauges, charts, maps, lists, drill-down, filters, layouts and export.

Install the core once — then add this AI module when the Agno bridge is available. Template packs keep working unchanged.

Same UX everywhere — chat, insights and explain run on any BoardKit board with Enable AI turned on.

AI capabilities

What managers get out of the box

1

Board chat

Ask questions about the visible figures. When requested, apply known date presets or board filters and reload the cards.

2

Insights

Append a narrative read of the current cards to the same chat panel, then keep asking follow-up questions.

3

Explain this tile

Open the card menu and choose Explain with AI. The explanation is added to the board chat thread.

4

Generate with AI

Turn a natural-language description into an unpublished board via import_config, ready for review.

5

Per-dashboard toggle

Enable AI on the board form so each dashboard can opt in or out. On by default; users still need the AI group.

6

Filter-aware context

Answers use the active date and filter context. Change filters while chatting and the next answer uses them.

Use AI on Dashboards — grant the group to users who may chat, summarize or explain. Managers inherit it and can generate boards.

Unpublished by design — generated boards stay private until you review items and publish them.

Security by design — ACLs and record rules of the source models are always enforced on the figures sent to the bridge.

Color systems

Presets and fully custom palettes

Custom palettes
