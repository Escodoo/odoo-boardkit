Install this module (it auto-installs when Boardkit Dashboard and CRM are both
installed).

As a Dashboard Manager, open _All Dashboards > Boards_, click _From template_,
and choose **CRM Pipeline**. Optionally rename the board in the wizard.

The board opens with the date filter on _This Month_. Open pipeline tiles
(Open Opportunities, Expected Revenue, Prorated Revenue, Overdue Closing) ignore
that filter so they always show the current pipeline. Won metrics use
_Closed Date_ and follow the date filter. Use the toggle filters (My
Opportunities, Open Pipeline, Won, Overdue Closing) to narrow the other cards.

Review the unpublished board, adjust items or filters, then publish and
optionally set a parent menu under CRM.
