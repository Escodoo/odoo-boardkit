Layouts that stick

Drag and resize the grid. Managers save the default; users keep a personal layout.

  • Gauge & list items — semicircular gauges and paginated record lists with click-through.
  • Export — per-item CSV / XLSX export honoring active filters.
  • Publish workflow — build privately, then publish; optional menu under any top-level app, restricted by groups.
  • Wall-ready — auto-refresh, server-side cache, duplication and JSON import/export.
  • Live preview — see the item while configuring, before saving.
  • Mobile — responsive one-column layout on small viewports.
Security by design. Data is always read with the access rights of the current user: ACLs and record rules of the source models are enforced.
