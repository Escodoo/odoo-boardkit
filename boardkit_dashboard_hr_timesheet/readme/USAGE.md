Install this module (it auto-installs when Boardkit Dashboard and Timesheets are
both installed).

As a Dashboard Manager, open _All Dashboards > Boards_, click _From template_,
and choose **Timesheet Overview**. Optionally rename the board in the wizard.

The board opens with the date filter on _This Month_. The Today Hours tile ignores
that filter so it always shows the current day. Other cards use the timesheet
_Date_ field and follow the date filter. Use the toggle filters (My Timesheets,
With Task, Without Task) to narrow the other cards.

Review the unpublished board, adjust items or filters, then publish and
optionally set a parent menu under Timesheets.
