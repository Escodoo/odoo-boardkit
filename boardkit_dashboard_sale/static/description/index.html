BoardKit Dashboard

Built on the BoardKit engine

This module is a template pack for BoardKit Dashboard — the open-source engine that builds analytic boards on any Odoo model with tiles, KPIs, gauges, charts, maps, lists, drill-down, filters, layouts and export.

  • Install the core once — then add the template modules you need; most auto-install when their app dependency is present.
  • Same UX everywhere — date filters, ad-hoc filters, publish workflow and personal layouts work the same across Sales, CRM, HR, Accounting and OCA apps.
  • Or start blank — create a board from scratch on any model if a template is not enough.
Requires BoardKit Dashboard. Find it on the same repository / Apps listing as boardkit_dashboard.
