Install this module (it auto-installs when Boardkit Dashboard, Mail and Calendar
are all installed).

As a Dashboard Manager, open _All Dashboards > Boards_, click _From template_,
and choose **My Day**. Optionally rename the board in the wizard.

Every card is already limited to the current user (assigned activities, meetings
you attend, your inbox and channels). Optional chips refine activities (Overdue
only, Due today) or channels (Chats only). There is no board-level date filter;
each card uses its own deadline / start / message date rules.

When installed with demo data, a published board is created from this template and exposed as a top-level app (sequence `-1`).
