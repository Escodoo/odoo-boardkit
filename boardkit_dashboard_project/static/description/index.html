BoardKit Project

Adds a curated Project Overview template that managers can instantiate from From template in the Boards catalogue. The board is built on project.task and lands unpublished so it can be reviewed before users see it. It focuses on task delivery: open and done counts, high-priority and overdue backlogs, completion rate, unassigned and waiting tasks, done trends, project and stage breakdowns, and a recent tasks list. Toggle filters cover my tasks, open tasks, overdue tasks and high priority.

BoardKit Dashboard

Built on the BoardKit engine

This module is a template pack for BoardKit Dashboard — the open-source engine that builds analytic boards on any Odoo model with tiles, KPIs, gauges, charts, maps, lists, drill-down, filters, layouts and export.

Install the core once — then add the template modules you need; most auto-install when their app dependency is present.

Same UX everywhere — date filters, ad-hoc filters, publish workflow and personal layouts work the same across apps.

Or start blank — create a board from scratch on any model if a template is not enough.

Requires BoardKit Dashboard. Find it on the same Apps listing as boardkit_dashboard.
